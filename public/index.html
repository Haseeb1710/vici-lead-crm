               VICIdial Admin Setup Checklist
            

            
    
              
  • 
                1.
                In VICIdial Admin → Users, ensure your API User (e.g. 6666) has User Level 8+ and Modify Leads = 1.
              
    • 
              
  • 
                2.
                Under the API User's API Functions permission, allow add_lead, external_dial, external_hangup, external_status, and external_pause (or set Allowed Functions to ALL).
              
    • 
              
  • 
                3.
                For Click-to-Dial, the agent must be logged into the VICIdial Agent Screen (/agc/vicidial.php) and in PAUSED or READY state.
